# 求解计划

---

## 一、题目总体方向

本题为微构体中导电介质填充的仿真优化问题，属于三维几何建模与蒙特卡洛模拟的复合问题。微构体是边长10000nm的立方体，默认填充绝缘介质，内部随机放置导电介质颗粒。导电介质分两类：金属A为长5000nm、底面半径30nm的直圆柱体，金属B为半径200nm的球体。导电判定规则为：两颗粒表面最短距离≤1.8nm时导通，微构体左右两侧（X=-5000和X=+5000面）为电极面，存在从一侧电极到另一侧电极的导电通路时微构体导通。边界条件为周期性截断：颗粒超出边界部分沿越界反方向平移一个边长（10000nm）从对侧重新进入。

核心任务递进：问题一分析单个金属A颗粒的导通条件，问题二计算多颗粒在不同填充率下的导通概率，问题三确定达到90%导通概率所需的最小填充率，问题四引入双金属成本优化。四个问题从单体分析到统计推断再到优化决策，层层递进。

## 二、各题求解思路

### 问题一：单金属A颗粒导通判断

**具体分析**：
- 输入：附件1中12个金属A颗粒的端点坐标（每行两个端点定义一根圆柱体轴线）
- 输出：每个颗粒对应的微构体是否导通（是/否），并计算导通概率
- 难点：周期性边界条件下，单根圆柱体可能被截断为多段，需要判断这些分段是否能连接两侧电极
- 定位：建立基本的几何模型和导通判定框架，为后续问题提供基础算法

**建模**：
核心问题是判断经过周期性边界处理后，一根长5000nm的圆柱体是否能同时触及两侧电极面（X=-5000和X=+5000）。具体步骤：
1. **周期性边界处理**：将圆柱体轴线（由两端点定义的线段）按周期性边界规则裁剪。若轴线超出立方体范围，将超出部分沿超界方向平移10000nm。经过处理后，一根圆柱体可能变为1~2个有效线段（因为长度为5000nm，在10000nm的立方体中最多跨越一个方向的边界两次，但由于周期边界最多被拆成2段）。
2. **电极距离计算**：对每个有效线段，计算其表面到X=-5000面和X=+5000面的最短距离。线段到平面的距离 = 线段上点到平面的最短距离 - 圆柱半径30nm。
3. **导通判定**：若存在一个分段触及X=-5000面（表面距离≤1.8nm）且同一分段或另一个分段触及X=+5000面（表面距离≤1.8nm），且这些分段属于同一圆柱体，则微构体导通。同时，若两个分段分别触及不同电极且两分段间的最短距离≤1.8nm，也判定为导通。
4. **统计**：导通概率 = 导通案例数 / 12。

**核心算法**：
- 线段与平面的最短距离
- 周期性边界下的线段裁剪
- 线段间最短距离（3D）

| 主方法 | 备选方法 | 适用场景 | 关键算法/工具 |
|--------|---------|---------|--------------|
| 几何解析法（线段到面距离+周期边界裁剪） | 网格采样法 | 精确计算，圆柱体轴线为直线段 | numpy, scipy.spatial.distance |

### 问题二：多金属A颗粒不同填充率下的导通概率

**具体分析**：
- 输入：附件2中49个金属A颗粒的坐标（固定配置），以及给定的填充率0.50%、0.60%、0.70%、1.00%
- 输出：各填充率下的导通概率
- 难点：需要在不同填充率下进行蒙特卡洛模拟（大量随机生成颗粒配置），每次模拟需要构建连通图并判断是否存在电极到电极的路径
- 定位：建立蒙特卡洛模拟框架，引入连通性判定算法（Union-Find），验证渗流理论

**建模**：
1. **体积计算**：单个金属A体积 = π × (30nm)² × 5000nm = 4.5π × 10⁶ nm³ ≈ 1.4137 × 10⁷ nm³。微构体总体积 = 10000³ = 10¹² nm³。
2. **颗粒数量确定**：填充率 = N × V_A / V_total，故 N = 填充率 × V_total / V_A。
   - 0.50%: N = 0.005 × 10¹² / (1.4137 × 10⁷) ≈ 354
   - 0.60%: N ≈ 424
   - 0.70%: N ≈ 495
   - 1.00%: N ≈ 707
3. **蒙特卡洛模拟**：每种填充率独立运行M次（M≥1000），每次随机生成N个颗粒（随机端点坐标，保证长度为5000nm），执行连通性判定，统计导通次数。
4. **连通性判定（Union-Find）**：
   - 每个颗粒为一个节点
   - 两颗粒间表面最短距离≤1.8nm → Union
   - 颗粒表面到X=-5000面距离≤1.8nm → 连接到虚拟"左电极"节点
   - 颗粒表面到X=+5000面距离≤1.8nm → 连接到虚拟"右电极"节点
   - 若"左电极"和"右电极"在同一集合 → 导通
5. **附件2固定配置**：对附件2中的49个颗粒也执行连通性判定，计算该具体配置的导通状态。

**颗粒间最短距离计算**：
- 线段到线段的最短距离（考虑周期性边界）：枚举一个颗粒的所有周期镜像（最多27个：{-10000, 0, +10000}³平移），计算两线段间最短欧氏距离，取最小值
- 表面距离 = 轴线最短距离 - 60nm（两个半径之和）

| 主方法 | 备选方法 | 适用场景 | 关键算法/工具 |
|--------|---------|---------|--------------|
| 蒙特卡洛 + Union-Find + 3D线段最短距离 | 渗透理论解析近似 | 精确模拟，但计算量大 | numpy, scipy.spatial, Union-Find数据结构 |

### 问题三：最小填充率确定（≥90%导通概率）

**具体分析**：
- 输入：附件3中535个颗粒（参考配置），目标导通概率≥90%
- 输出：仅使用金属A时的最小填充率（精确到百分号后两位小数）
- 难点：需要在填充率空间中搜索临界值，每次评估需要大量蒙特卡洛试验
- 定位：将问题转化为二分搜索/迭代逼近问题，利用渗流理论的相变特性

**建模**：
1. **临界现象**：导电复合材料存在渗流阈值，填充率低于阈值时导通概率接近0，高于阈值时快速上升至接近1。本题需要在阈值附近精确搜索。
2. **二分搜索**：在[0.30%, 2.00%]区间内二分搜索，每次中点填充率运行M次蒙特卡洛（M≥500），估计导通概率。若概率<90%，搜索右半区间；否则搜索左半区间。收敛到精度0.01%。
3. **大样本验证**：对搜索到的临界填充率，运行更大规模蒙特卡洛（M≥2000）以验证概率确实≥90%。
4. **附件3分析**：计算附件3中535个颗粒的填充率，验证其导通状态，作为参考。

| 主方法 | 备选方法 | 适用场景 | 关键算法/工具 |
|--------|---------|---------|--------------|
| 二分搜索 + 蒙特卡洛 | 渗流理论公式近似 | 精确定位阈值 | numpy, scipy.optimize |

### 问题四：双金属成本优化

**具体分析**：
- 输入：金属A成本1.05元/μm³，金属B成本0.05元/μm³；金属A半径30nm、长5000nm；金属B半径200nm
- 输出：在导通概率≥90%条件下，使总成本最低的金属A和金属B的最优数量
- 难点：两个变量的二维优化空间，且每次评估成本高
- 定位：在问题三基础上引入金属B，利用球形颗粒的低成本特性降低总成本

**建模**：
1. **金属B体积**：V_B = 4/3 × π × (200nm)³ ≈ 3.3510 × 10⁷ nm³
2. **金属A体积**：V_A = π × 30² × 5000 ≈ 1.4137 × 10⁷ nm³
3. **成本函数**：Cost = 1.05 × N_A × V_A + 0.05 × N_B × V_B（单位：元，需注意体积单位为μm³）
   - 1nm³ = 10⁻⁹ μm³，所以实际转换需要小心。但这里成本系数直接按nm³计算即可，因为是比较相对值。
   - 实际：V_A = 1.4137 × 10⁷ nm³ = 1.4137 × 10⁻² μm³，V_B = 3.3510 × 10⁷ nm³ = 3.3510 × 10⁻² μm³
4. **优化策略**：二维网格搜索。固定N_A，对每个N_A搜索使导通概率≥90%的最小N_B，计算成本，取全局最优。
   - N_A范围：0到问题三确定的临界数量
   - 对每个N_A，二分搜索最小N_B
5. **颗粒间距离**：金属A（圆柱体）与金属B（球体）之间的表面距离 = 球心到线段的最短距离 - 30nm - 200nm

| 主方法 | 备选方法 | 适用场景 | 关键算法/工具 |
|--------|---------|---------|--------------|
| 二维网格搜索 + 二分 + 蒙特卡洛 | 遗传算法/粒子群 | 精确穷举小范围 | numpy |

## 四、操作步骤

### 问题一
1. 加载附件1中12个颗粒的端点坐标
2. 对每个颗粒：应用周期性边界条件，将轴线裁剪为有效分段
3. 计算每个分段到X=-5000面和X=+5000面的最短距离
4. 综合考虑分段间连接性，判定导通
5. 统计导通概率，生成图表

### 问题二
1. 计算各填充率对应的颗粒数量N
2. 对附件2中49个颗粒的固定配置执行连通性判定
3. 对每种填充率运行蒙特卡洛模拟（≥1000次）
4. 每次模拟：随机生成N个颗粒 → 周期性边界处理 → 计算两两距离 → Union-Find连通性判定
5. 汇总结果，生成图表

### 问题三
1. 确定二分搜索区间和精度
2. 迭代：对区间中点填充率运行蒙特卡洛（≥500次）估计概率
3. 根据概率结果缩小区间
4. 收敛后大样本验证
5. 分析附件3配置

### 问题四
1. 确定N_A和N_B的搜索范围
2. 对每对(N_A, N_B)运行蒙特卡洛估计导通概率
3. 筛选满足≥90%概率的组合
4. 计算各组合成本，取最小值
5. 大样本验证最优配置

## 六、异常预案

- **周期边界裁剪复杂情况**：若单颗粒经周期边界后被拆成超过2段（在极端情况下可能跨越多个面的角点），改为采样方法在颗粒表面均匀取点，逐点判断与电极的距离
- **蒙特卡洛收敛慢**：若导通概率在50%附近（方差最大），增加模拟次数至5000+次确保标准误差<1%
- **颗粒间距离计算瓶颈**：N较大时两两计算距离为O(N²)，使用空间哈希/KD-Tree加速近邻搜索，仅对近邻颗粒精确计算距离
- **二分搜索不收敛**：若概率曲线在阈值附近不够单调（有限样本的统计波动），改用0.01%步长的线性扫描+平滑
- **问题四搜索空间过大**：若N_A×N_B网格超过10000个点，先用粗网格（步长10）筛选，再在最优区域细网格（步长1）搜索
- **内存不足**：大规模蒙特卡洛时控制批次大小，分批处理并汇总结果
