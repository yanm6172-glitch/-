# 减重打卡 · 微信小程序

一个给「168cm / 100kg → 目标 65kg」定制的减肥打卡小程序。具备**APP 规范的用户账号体系**（登录页 + 协议同意 + 资料管理 + 退出登录），运行于微信小程序内。

## 使用步骤（想在微信里用，必须走这几步）

### 第 1 步：注册小程序账号（免费）
1. 浏览器打开 https://mp.weixin.qq.com
2. 点「立即注册」→ 选「小程序」→ 邮箱注册 → **主体类型选「个人」**（用身份证，免费，无需营业执照）
3. 注册完成后，在「设置 → 开发管理 → 开发设置」里复制你的 **AppID**

### 第 2 步：安装微信开发者工具
1. 下载（稳定版）：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. 安装后用微信扫码登录

### 第 3 步：导入本项目
1. 打开开发者工具 → 「+」导入项目
2. 目录选择本文件夹（`F:\微信小程序`）
3. AppID 填你自己的（第 1 步拿到的）；想先随便看看也可以选「测试号」
4. 点「确定」，左侧模拟器里就能看到小程序运行效果

### 第 4 步：在你自己手机上用
- 开发者工具顶部点「**预览**」→ 用手机微信扫码 → 手机里就能打开用了
- 注意：预览版只有**你本人微信**能打开

### 第 5 步（可选）：让家人朋友一起用
1. 开发者工具点「**上传**」→ 填个版本号如 1.0.0
2. 回到 mp.weixin.qq.com 后台 →「管理 → 版本管理」→ 找到刚上传的版本，设为「**体验版**」
3. 「管理 → 成员管理」→ 添加**体验成员**（扫对方的微信码邀请）
4. 对方扫体验版二维码即可使用

### 第 6 步（可选）：正式发布，任何人可用
- 后台「版本管理」→ 提交审核 → 类目按后台可选项选择（个人主体类目有限，建议选「工具」类下合适的子类目）
- 审核一般 1~7 天，通过后点「发布」，所有人都能搜到/分享使用

## 扫码记热量（重要配置）

「热量」页通过扫描条形码查询 **Open Food Facts** 免费食品数据库获取每 100g 热量。

- **开发调试阶段**：开发者工具右上角「详情 → 本地设置」勾选 **「不校验合法域名」**，即可在模拟器和预览中正常扫码查询。
- **体验版/正式版**：必须在小程序后台（mp.weixin.qq.com → 开发管理 → 开发设置 → 服务器域名）配置：
  - `request` 合法域名：`https://world.openfoodfacts.org`
  - `downloadFile` 合法域名：`https://images.openfoodfacts.org`（用于显示商品图片，不配也能用，只是不显示图）
- **数据源说明**：Open Food Facts 对进口/预包装食品覆盖较好，**国产食品经常查不到**。查不到时页面会提示，可对照包装上的营养成分表用「手动添加」记录（每100g千卡 × 克数）。
- 若该国外服务器网络不稳定导致查询失败，同样用「手动添加」或「常用食物」记录即可。

## 云开发配置（云同步 / 家人监督 / 打卡提醒，三步开通）

> 这三个功能都基于微信云开发（个人免费额度够用）。**前提：使用真实 AppID**（测试号无法使用云开发）。不用这些功能可跳过本节，其余功能不受影响。

### 第 1 步：开通云开发并填入环境 ID
1. 开发者工具顶部点「**云开发**」→ 按提示开通（选基础套餐，有免费额度）
2. 创建一个环境，复制**环境 ID**（形如 `xxx-1a2b3c`）
3. 打开 `utils/config.js`，把 `cloudEnv: 'YOUR-ENV-ID'` 改成你的环境 ID

### 第 2 步：部署三个云函数
1. 开发者工具左侧文件树找到 `cloudfunctions` 目录下的 `login`、`family`、`reminder`
2. 分别右键 →「**上传并部署：云端安装依赖**」
3. `reminder` 还需右键 →「**上传触发器**」（定时每30分钟检查一次到点提醒）

### 第 3 步：配置订阅消息模板（打卡提醒用）
1. mp 后台「功能 → 订阅消息」→ 在公共模板库选两个提醒类模板（如「健身提醒」），记下**模板 ID**
2. 把模板 ID 填入 `utils/config.js` 的 `remind.water.id` 和 `remind.weigh.id`
3. **注意**：`remind.water.data` 里的字段名（`thing1`/`time2`）要和所选模板的字段一致，不一致请照着模板改
4. `cloudfunctions/reminder/index.js` 里的 `MINI_STATE`：开发调试改 `'developer'`，体验版改 `'trial'`，正式发布用 `'formal'`

### 第 4 步：配置拍照识别（热量页「拍食物」，可选）
1. ~~注册智谱 AI 开放平台（免费）：https://open.bigmodel.cn → 控制台拿到 **API Key**~~ ✅ **API Key 已配置**
2. 在开发者工具右键 `cloudfunctions/vision` 文件夹 →「**上传并部署：云端安装依赖**」
3. 热量页点「📸 拍食物」→ 拍照 → AI 识别食物、估算克重并计算热量；识别不准可改克数或转手动输入

### 关于打卡提醒的机制（重要）
- 个人主体一般是「**一次性订阅**」：每授权一次只能发一条通知。
- 本程序的处理：每天第一次打开小程序时弹窗问「订阅今天的提醒？」，点确认即授权当天一条；也可在「我的 → 打卡提醒 → 订阅提醒」手动订阅。
- 若所选模板支持「总是保持以上选择」（长期订阅），授权一次后每天自动发，无需重复订阅。

### 云同步与家庭组
- **云同步**：本地数据变化 3 秒后自动上传；换设备首次打开自动拉取云端较新数据。「我的」页可手动「立即同步」。数据库集合 `sync` 会自动创建，保持默认权限（仅创建者可读写）即可。
- **家人监督**：一人「创建家庭组」得到 6 位邀请码 → 家人填写自己的昵称并在「我的 → 家人监督」输入邀请码加入 → 点「查看家人」互看今日打卡得分/热量。家人数据来自各自的云同步记录（家人需同样开通云开发并在同一小程序使用）。

## 账号体系说明（APP 规范，运行于微信小程序）

- **微信一键登录**：采用小程序标准登录流程（`wx.login` → 云函数 `login` 换取 openid），openid 即账号身份；无需密码。
- **资料管理**：「我的」页顶部资料卡支持更换头像（微信头像选择器）和昵称（`type="nickname"` 快捷填写），资料保存到云端 `users` 集合。
- **协议合规**：登录页需勾选《用户协议》《隐私政策》方可登录（发布审核必需）。
- **游客模式**：未配置云开发时自动降级为本地体验模式（数据仅存本机），配置后可通过「我的 → 去登录」升级为微信登录，本地数据自动并入云同步。
- **退出登录**：清除本地登录会话（数据保留），回到登录页。
- **个人主体限制**：个人主体小程序**无法获取手机号**（`getPhoneNumber` 仅企业主体可用），故采用「微信 openid + 头像昵称」方案，这是个人主体的标准做法。

## 发布审核注意事项

1. **用户隐私保护指引**：mp 后台「设置 → 服务内容声明 → 用户隐私保护指引」需声明收集 openid、昵称、头像、打卡数据等信息及用途，内容与 `pages/agreement/agreement.js` 中的《隐私政策》保持一致。
2. **类目选择**：个人主体可选类目有限，建议选择「工具」类下的合适子类目；文案避免医疗功效承诺（当前文案已规避）。
3. 登录页必须含协议勾选（已实现），否则审核会被驳回。

## 常见问题

- **预览二维码打不开？** 确认 AppID 是真实 AppID 而非测试号，且开发者工具已登录你的微信。
- **扫码查不到商品？** 国产食品在 Open Food Facts 里覆盖不全，属正常现象，用「手动添加」按包装标注记录即可；正式使用时记得按上文配置 request 合法域名。
- **想改颜色/文字？** 颜色在 `app.wxss` 和各页 `.wxss`（主题绿 `#16a34a`）；规则文案在 `pages/me/me.wxml`。
- **想加新功能？** 可继续扩展：打卡日历、周报、食物热量库（国产库）、云端同步、家人互相监督等。
