## 一、用户隐私保护指引（发布前必填，漏了必被驳回）

**位置**：mp.weixin.qq.com → 设置 → 服务内容声明 → 用户隐私保护指引 → 更新

**声明处理的信息**（逐条添加，照抄）：

### 信息类型 1
- 处理的信息类型：**用户身份与登录信息（微信 openid）**
- 处理目的：**用于识别用户账号、保持登录状态、多设备数据同步与家人组功能**
- 使用场景：**用户登录小程序、开启云同步、使用家人监督功能时**

### 信息类型 2
- 处理的信息类型：**用户主动填写的昵称与头像**
- 处理目的：**在家人监督与消息中心等功能中展示用户身份**
- 使用场景：**用户编辑个人资料、加入家庭组时**

### 信息类型 3
- 处理的信息类型：**健康打卡数据（体重、饮食记录、食物热量、饮水量、步数、运动、日常花费、打卡得分）**
- 处理目的：**生成打卡记录、趋势图表、周报统计、成就勋章等核心功能展示**
- 使用场景：**用户记录体重、扫码记热量、每日打卡、查看报告时**

### 信息类型 4
- 处理的信息类型：**用户拍摄/上传的食物照片（用于拍照识别热量）**
- 处理目的：**识别食物名称、估算克重并计算热量**
- 使用场景：**用户在热量页使用「拍食物」功能时**
- 说明：照片仅临时用于识别计算，识别完成后不长期保存

**存储与删除说明**（指引中的说明栏）：
> 数据默认仅存储在用户设备本地。用户开启云同步后，数据将存储于微信云开发数据库，仅用于多设备同步；用户加入家庭组后，组内成员仅可见昵称、当日打卡得分与热量等摘要信息。用户可在「我的-数据管理」随时清除全部数据。

## 二、订阅消息模板选择建议

**位置**：功能 → 订阅消息 → 公共模板库

- 搜索关键词建议：**「提醒」「健身」「健康」「喝水」**
- 选 2 个**一次性订阅**模板，分别用于喝水提醒、称重提醒
- 模板字段里需包含**提醒内容（thing）**和**提醒时间（time/date）**两类字段
- 拿到模板 ID 后填入 `utils/config.js`，字段名与模板不一致时照着模板改 `data` 的键名

## 三、类目选择说明

- 提交审核时，个人主体可选类目有限，按后台实际列表选择，建议顺序：
  1. **工具 → 效率 / 健康管理**（如有）
  2. **生活服务**下的记录类子类目
  3. 都不行就选「**工具**」最接近的通用子类目
- 页面与文案全程避免"治疗""疗效""减肥成功"等医疗承诺字眼（当前文案已规避）

## 四、审核自查清单（逐项打勾）

- [x] 登录页含《用户协议》《隐私政策》勾选（未勾选无法登录）
- [x] 隐私政策页内容与后台「用户隐私保护指引」一致（见本文档第一节）
- [x] 提供数据删除路径：我的 → 数据管理 → 清除全部打卡数据
- [x] 全文无医疗功效承诺
- [x] 无未使用权限申请（仅扫码调用相机，一次性授权）
- [ ] 类目与实际功能相符
- [ ] 域名配置：request 合法域名 `https://world.openfoodfacts.org`（扫码记热量用；未配置则扫码功能在正式版不可用，但其余功能不受影响）

## 五、上传版本备注文案（提交审核时填）

> 个人健康打卡记录工具。提供体重记录与趋势预测、扫码记录食物热量（含185种中国食物库）、每日饮水/步数/211饮食/运动/花费打卡、每周报告与打卡日历、成就勋章。无任何医疗诊断治疗功能，数据以本地存储为主。

## 六、测试账号说明（审核备注栏，如要求填写）

> 无需测试账号：小程序通过微信授权登录，首次打开即自动创建账号；未配置云环境时自动进入本地体验模式，全部打卡功能可正常使用。
