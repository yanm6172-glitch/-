## 第 1 步：注册小程序（免费，约 10 分钟）

1. 打开 https://mp.weixin.qq.com
2. 右上角「立即注册」→ 选择「**小程序**」
3. 用一个**没注册过公众号/小程序的邮箱**注册 → 收邮件点激活链接
4. 主体类型选「**个人**」→ 填身份证、手机号、微信扫码验证
5. 完成后进入小程序后台 → 左侧「设置 → 开发管理 → 开发设置」→ 复制 **AppID**（形如 wx1234567890abcdef）

> ⚠️ 个人主体：免费、无需营业执照。可以发布小程序，只是不能用微信支付/手机号登录等企业功能（本小程序已规避这些）。

## 第 2 步：导入项目并首次预览（约 10 分钟）

1. 打开微信开发者工具 → 微信扫码登录
2. 点「+」→ 导入项目：
   - 目录：`F:\微信小程序\jianfei-miniprogram`
   - AppID：填第 1 步拿到的（**不要选测试号**，测试号无法真机预览和用云开发）
3. 点「确定」→ 左侧模拟器应出现**登录页**
4. 顶部工具栏点「**预览**」→ 用手机微信扫码 → 手机上打开体验
5. 手机上：勾选协议 → 点「微信一键登录」→ 此时未配置云开发，会进入**本地体验模式**，所有打卡功能都可先用

> ✅ 到这一步，小程序已经"能用"了（只有你自己能打开）。
> 想省事，可以跳过第 3、4 步直接去第 5 步（但云同步/家人/提醒/正式登录这些功能会不可用）。

## 第 3 步：开通云开发 + 部署云函数（约 15 分钟，启用登录/云同步/家人/提醒）

1. 开发者工具顶部点「**云开发**」按钮 → 同意开通 → 选「按量付费」基础套餐（有免费额度，个人用基本不花钱）
2. 创建一个环境（环境名随意）→ 复制**环境 ID**（形如 `xxx-1a2b3c`）
3. 打开 `utils/config.js`，把 `cloudEnv: 'YOUR-ENV-ID'` 改成你的环境 ID
4. 左侧文件树展开 `cloudfunctions`，对 **login、family、reminder** 三个文件夹**分别右键 →「上传并部署：云端安装依赖」**（每个约 1 分钟）
5. `reminder` 再右键 →「**上传触发器**」（定时发送提醒用）
6. 回到模拟器 → 编译 → 手机上重新预览 → 登录页点「微信一键登录」→ 这次走**正式登录**（获取 openid 建账号）

> 数据库集合 `sync`/`users`/`families`/`reminders` 会在第一次使用时自动创建，权限保持默认即可，不用手动建。

## 第 4 步（可选）：拍照识别 + 订阅消息提醒（各约 5 分钟）

### 4a. 拍照识别食物（热量页「拍食物」）
1. ~~注册智谱 AI 开放平台（免费）：https://open.bigmodel.cn → 拿到 **API Key**~~ ✅ **API Key 已配置好**
2. 开发者工具右键 `cloudfunctions/vision` 文件夹 →「**上传并部署：云端安装依赖**」
3. 热量页点「📸 拍食物」拍照即用；识别不准可改克数或转手动

### 4b. 订阅消息提醒
1. mp 后台「功能 → 订阅消息」→「公共模板库」搜索「**提醒**」→ 选两个提醒类模板（比如"健身提醒"）→ 添加到我的模板 → 复制**模板 ID**
2. 填入 `utils/config.js`：
   - `remind.water.id` = 喝水提醒模板 ID
   - `remind.weigh.id` = 称重提醒模板 ID
   - 模板字段名和 `thing1`/`time2` 不一致时，照着模板的字段改 `data` 里的键名
3. `cloudfunctions/reminder/index.js` 里的 `MINI_STATE`：开发调试改 `'developer'`，体验版改 `'trial'`，正式发布用 `'formal'`

## 第 5 步：让家人一起用（体验版，约 10 分钟）

1. 开发者工具点「**上传**」→ 版本号填 `1.0.0`，备注随意
2. mp 后台「管理 → 版本管理」→ 开发版本列表找到刚上传的 → 设为「**体验版**」
3. mp 后台「管理 → 成员管理 → 体验成员」→ 添加家人的微信号（扫家人的码邀请）
4. 家人打开体验版二维码即可使用（先各自在「我的」页创建/加入家庭组）

## 第 6 步：正式发布（1~7 天等审核）

> 📋 本步骤所有要填的文案（隐私指引逐字段内容、类目说明、审核自查清单、版本备注）都已写好在同目录的 **《上线材料包.md》** 里，照抄即可。

1. **配置用户隐私保护指引**（必做，漏了必被驳回）：
   - mp 后台「设置 → 服务内容声明 → 用户隐私保护指引」→ 按《上线材料包.md》第一节逐条填写
2. mp 后台「管理 → 版本管理」→ 开发版本 → 「提交审核」：
   - 类目：按《上线材料包.md》第三节建议选择
   - 版本备注：复制《上线材料包.md》第五节文案
3. 审核通过后点「**发布**」→ 所有人都能搜索/分享使用 🎉

## 🔧 常见报错速查

| 现象 | 原因与解决 |
|---|---|
| 预览二维码提示"未找到 AppID" | `project.config.json` 里还是 `touristappid`，改成你的真实 AppID |
| 登录提示"登录失败，请检查云函数" | `login` 云函数没部署，或 `config.js` 的 cloudEnv 没填/填错 |
| 提示 `cloud init error` | 环境 ID 填错，或没在工具里开通云开发 |
| 扫码查热量一直失败 | 开发者工具「详情 → 本地设置」勾选**不校验合法域名**；正式发布前在后台配 `request` 域名（见 README） |
| 订阅消息发不出去 | 模板 ID 未填/填错；字段名与模板不符；`MINI_STATE` 与当前环境不匹配 |
| 深色模式没反应 | 需要基础库 2.11.0+；开发者工具「详情 → 本地设置」里选最新调试基础库 |
| 修改了 config.js 不生效 | 改完要点工具上的「编译」重新构建 |
| 模拟器正常、真机异常 | 大概率是域名/云函数权限问题，把真机报错截图发 AI |
